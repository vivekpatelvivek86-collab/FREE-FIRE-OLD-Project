# FREE-FIRE-OLD-Project
Experience of Old Free Fire is an Unreal Engine 5.4 C++ game project targeting Android. This repository contains the game source code, project configuration, and GitHub Actions workflows for automated Android APK builds.
# 🎮 Experience of Old Free Fire

An Android-focused battle royale game project inspired by the classic
battle royale experience of 2019.

## 📱 About the Project

Experience of Old Free Fire is a C++ game project built around Unreal
Engine 5.4, with Android as its target platform.

The goal is to develop a mobile battle royale experience with classic
gameplay-inspired mechanics and mobile-friendly controls.

## ✨ Planned Features

- 🎮 Mobile-friendly controls
- 🗺️ Battle royale-style environment
- 🔫 Combat and weapon mechanics
- 🎒 Loot and inventory systems
- 🤖 Bot-based gameplay
- 📱 Android support
- ⚙️ Automated APK build workflow

*Features and compatibility are subject to development and testing.*

## 📦 Android APK
