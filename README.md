## 📖 About the Project

**Experience of Old Free Fire** is an independent C++ game development project designed with Android devices in mind.

The project's vision is to capture the nostalgic feeling of classic 2019-era mobile battle royale games while developing its own gameplay systems, environments, controls, and identity.

The project uses **Unreal Engine 5.4** as its intended game engine, with a focus on Android development and mobile-friendly gameplay.

Our goal is to develop, build, test, and eventually distribute an Android APK.

## 🎯 Our Vision

- 🎮 Create an enjoyable classic-inspired mobile battle royale experience.
- 📱 Focus on Android compatibility and touch controls.
- 🌍 Develop immersive game environments and gameplay systems.
- ⚔️ Build combat, weapons, loot, and survival mechanics.
- 🤖 Develop bot-based gameplay for testing and practice.
- 🛠️ Improve stability and performance through testing.
- 📦 Make verified Android builds available when ready.

## 🚀 Automated Build Workflow

The project aims to use GitHub Actions to automate parts of the Android build process.

The planned workflow includes:

1. Checking out the repository.
2. Extracting the project archive when required.
3. Checking the project files and build environment.
4. Configuring the required Android build dependencies.
5. Attempting to compile and package the project.
6. Uploading the APK as a downloadable artifact if the build succeeds.

**Important:** Automated builds require a compatible Unreal Engine installation and Android toolchain. A successful workflow configuration alone does not guarantee a successful APK build.
