# 🎮 About the Project

**Experience of Old Free Fire** is an independent game development project focused on creating an Android battle royale experience inspired by the nostalgia of classic-era mobile gaming.

The project aims to combine familiar old-school gameplay ideas with an independently developed game, its own implementation, and a mobile-first design approach.

Built around **Unreal Engine 5.4 and C++**, the project is intended to evolve through iterative development, automated build attempts, and real-device testing.

Our ambition is simple:

> **Bring the feeling of classic mobile battle royale gaming into a new, independent experience.**

This is a work in progress. The project will continue to evolve as features are implemented, builds become available, and testing progresses.

---

# 👑 Our Mission

We want to build a game experience that prioritizes:

- 🎯 **Classic-inspired gameplay** — Focus on the nostalgic feel of the 2019-era battle royale experience.
- 📱 **Mobile-first design** — Design gameplay and controls with Android devices in mind.
- ⚔️ **Action-oriented combat** — Develop weapon, combat, and survival systems.
- 🌍 **Immersive environments** — Build environments that support exploration and combat.
- 🤖 **AI opponents** — Work toward bot-based gameplay and practice scenarios.
- ⚙️ **Continuous improvement** — Identify problems, fix bugs, and improve stability.
- 🚀 **Accessible releases** — Publish Android builds when they have been successfully generated and tested.

# ⚙️ Automated Android Builds

The project aims to use GitHub Actions to automate parts of the Android build process.

The planned workflow is intended to:

1. Check out the repository.
2. Extract the project archive when required.
3. Validate the Unreal project files.
4. Check the required build tools and dependencies.
5. Attempt the Android compilation and packaging process.
6. Upload the APK as a downloadable artifact if packaging succeeds.
7. Preserve build logs to help diagnose failures.

### Important build requirements

An Unreal Engine Android build requires a compatible Unreal Engine installation and a correctly configured Android toolchain.

GitHub Actions does not automatically provide a licensed and ready-to-use Unreal Engine installation. Runner storage, available memory, installation access, and build duration may also affect success.

**Build status will be reported according to actual workflow results—not assumptions.**
